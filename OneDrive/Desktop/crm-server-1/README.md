# 🚀 Sanitize Subdomain API

A clean, modular Node.js Express API to sanitize subdomain strings.

## ✅ Features
- Converts input to lowercase
- Removes invalid characters
- Middleware validation
- Controller separation
- Optional MySQL storage

## 🛠️ Setup
```bash
git clone https://github.com/your-username/sanitize-subdomain-api.git
cd sanitize-subdomain-api
npm install
npm start
